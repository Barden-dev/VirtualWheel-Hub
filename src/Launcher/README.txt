vWheel Hub

Windows: run vWheelHub.exe. Linux: run ./vWheelHub.
Keep the app/ directory next to the launcher. Move or extract the whole folder.
The launcher passes arguments and the exit code through to the application.
Profiles and settings remain in the existing user data directories.
